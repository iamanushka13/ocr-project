# ocr-project
Optical Character Recognition (OCR) tool designed to extract text from images. This project processes raw images, enhances them for better visibility, and outputs digitized, machine-readable text.

## Features
* **Accurate Text Extraction:** Converts images (PNG, JPEG, etc.) into editable text.
* **Image Preprocessing:** Includes built-in filters (grayscale, thresholding, noise reduction) to improve OCR accuracy on low-quality images.
* **Lightweight & Fast:** Optimized for quick inference and low resource consumption.

## 🛠️ Technologies Used
* **Python 3.x**
* **Tesseract OCR**
* **OpenCV** (for image preprocessing)
